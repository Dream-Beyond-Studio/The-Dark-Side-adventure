Wprowadzenie

Poniżej znajduje się szczegółowy opis wszystkich funkcji użytych w projekcie. Dokumentacja jest podzielona na pliki źródłowe.

Backend: server.js (Core)

Function log(category, message)

Odpowiada za logowanie zdarzeń w konsoli serwera oraz zapisywanie ich do pliku tekstowego.

ParametrTypOpis
categoryStringKategoria logu (np. 'CHAT', 'BUILD', 'KILL').
messageStringTreść wiadomości.
Zapisuje linię do pliku server_logs.txt z datą i godziną.

Function getTerrainHeight(worldX)

Proceduralne generowanie terenu. Używa dwóch fal sinusowych (Octaves) do stworzenia naturalnie wyglądających pagórków.

Math.sin(x * 0.1) * 8 + Math.sin(x * 0.05) * 12
Zwraca: Number (Wysokość terenu w blokach)

Function spawnCowNearPlayer()

Wybiera losowego gracza i tworzy krowę w jego pobliżu (zakres +/- 800px).

Sprawdza wysokość terenu w wylosowanym miejscu, aby krowa nie zrespiła się pod ziemią ani w powietrzu.

Function handleCommand(socket, commandString)

Parser komend administratora i gracza.

KomendaDziałanie
/nickAktualizuje nick w obiekcie gracza i wysyła event playerNickUpdate.
/tpZmienia koordynaty X/Y gracza i wysyła event teleport.
/sayWysyła wiadomość czatu z ID 'SERVER' (kolor czerwony).

Frontend: main.js

Function castRay(x1, y1, x2, y2)

Implementacja algorytmu Raycasting (rzucanie promienia). Służy do sprawdzania, czy laser w coś trafił.

Algorytm porusza się od punktu (x1,y1) do (x2,y2) w krokach co 4 piksele. W każdym kroku sprawdza ID bloku w world.js.

WyjątkiOpis
0, 12, 3, 4, 1Promień PRZENIKA przez Powietrze, Wodę, Tło i Trawę.
Zwraca: { x, y, hit: boolean } - Punkt trafienia.

Function updateMouseWorldPosition()

Przelicza pozycję kursora myszy na ekranie (Screen Space) na pozycję w świecie gry (World Space) uwzględniając przesunięcie kamery.

Zawiera logikę blokady budowania w powietrzu: sprawdza czy sąsiednie kafelki (góra, dół, lewo, prawo) są puste.

Function initPlayerPosition()

Skanuje pionową linię mapy na x=0 w poszukiwaniu pierwszego stałego bloku od góry, aby bezpiecznie ustawić gracza na ziemi po dołączeniu lub respawnie.

Function loop()

Główna pętla renderowania klienta (RequestAnimationFrame). Wywołuje kolejno:

  1. updatePlayerPhysics (Fizyka)
  2. Aktualizację Kamery (Centrowanie na graczu)
  3. Wysłanie pozycji do serwera (Socket emit)
  4. drawWorld, drawMobs, drawPlayer (Renderowanie)

Grafika: render.js

Function lerpColor(c1, c2, factor)

Interpolacja liniowa między dwoma kolorami RGB.

Używana do płynnego przejścia koloru nieba (np. od Nocy do Świtu).

Zwraca: String (np. "rgb(100,200,255)")

Function getSmoothSkyColor(progress)

Oblicza kolor tła na podstawie postępu dnia (0.0 - 1.0).

  • 0.00 - 0.20: Noc -> Świt
  • 0.20 - 0.70: Dzień
  • 0.70 - 0.80: Zachód słońca
  • 0.80 - 1.00: Noc

Function drawCelestialBodies(ctx, w, h, progress)

Rysuje słońce i księżyc poruszające się po łuku (sinus/cosinus).

Obiekty mają dodany efekt poświaty (Gradient Radialny).

Function drawWorld(ctx, camera, w, h, time, dayDuration)

Główny renderer świata. Optymalizacja: Rysuje tylko te kafelki, które mieszczą się w widoku kamery (View Frustum Culling).

Function drawPlayer(ctx, player, camera)

Rysuje postać z prymitywów (prostokąty). Zawiera logikę animacji kończyn:

offset = Math.sin(player.x * 0.2)

Sprawia to, że nogi i ręce machają tylko wtedy, gdy zmienia się pozycja X gracza.

Fizyka: physics.js

Function updatePlayerPhysics(player, keys)

Serce ruchu postaci. Obsługuje:

MechanikaOpis
GrawitacjaStałe przyspieszenie w dół (velY += GRAVITY).
WodaJeśli w bloku 12: grawitacja jest mniejsza, ruch wolniejszy, skok wyższy (wypływanie).
Kolizje XSprawdza blok po lewej/prawej stronie. Zeruje velX przy zderzeniu.
Kolizje YSprawdza sufit i podłogę. Ustawia grounded = true przy lądowaniu.

Świat: world.js

Function getTile(x, y) / setTile(x, y, type)

Zarządza globalną mapą podzieloną na Chunki.

Jeśli zapytasz o kafelek w chunku, który nie istnieje, funkcja automatycznie wywoła generateChunk.

Function generateChunk(chunkX)

Generuje pionowy wycinek świata o szerokości 16 bloków (CHUNK_SIZE).

Algorytm:

  1. Oblicz wysokość terenu dla każdego X.
  2. Wypełnij od dołu do wysokości terenu Kamieniem i Ziemią.
  3. Wypełnij resztę powietrzem.
  4. Dodaj wodę poniżej poziomu morza (SEA_LEVEL).
  5. Losowo generuj drzewa (Bloki 3 i 4) na trawie.
